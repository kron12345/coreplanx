# Codex Prompt: Order List Create Focus And CTA Contrast

## Purpose
Improve the order creation flow on the orders page by increasing CTA contrast and keeping the new order in focus after save.

## Context
- Related spec: `/specs/orders-create-focus-and-cta-contrast.md` (Rules: R1, R2, R3, R4, R5)

## Instructions
- Ensure the hero CTA `Neuer Auftrag` has clear contrast on the blue hero background (R1).
- After a successful order creation, focus the created order card in the list (R2).
- Keep the created card expanded and scrolled into view (R3).
- Do not reset filters or search automatically during the focus flow (R4).
- Place the focused card close to the top of the visible list area to keep maximum room for expanded content below (R5).

## Expected Output
- Updated UI styling for CTA readability.
- Updated create flow that keeps users on the newly created order card for immediate work.
